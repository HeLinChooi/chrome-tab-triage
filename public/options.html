What to look at

Morning digest

macOS and Windows can silently swallow Chrome notifications even when Chrome thinks it sent one. If the digest never shows up, switch to a dashboard tab — it cannot be suppressed. Notification mode already falls back to a tab whenever Chrome reports a failure.

A summary is a snapshot taken when the run starts. Reordering tabs or dragging them between windows during a run is safe — a tab keeps its identity when it moves. Closing or navigating a tab mid-run is what skews things: it may be counted with the page it had a moment ago, or appear in the report having already gone. With the Claude estimator a run takes a few seconds, so this is worth knowing but rarely worth waiting for.
